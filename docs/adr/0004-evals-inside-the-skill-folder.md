# Evals live inside the skill folder, in the agentskills.io format

Each skill keeps its eval scenarios in `evals/evals.json` inside its own folder, in the format of the agentskills.io guide "Evaluating skills" (prompt, expected output, assertions, human feedback). Anthropic alone documents three incompatible formats (the agentskills.io and `skill-creator` one, the example JSON in the best practices, and `claude plugin eval`, which requires a plugin). We picked the one from the open standard, which `skill-creator` also reads. Keeping evals in the skill folder means `npx skills` installs them along with the skill. They cost no agent context, and the skill stays self-contained in any repo, which matters because `creating-skills` is generic and cannot assume this repo's layout.
