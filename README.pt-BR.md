# skills

Skills de agente do [sa/mo](https://eusouosalmo.dev) para escrever, roteirizar vídeos e preparar repositórios para trabalhar com IA. Seguem a [especificação Agent Skills](https://agentskills.io/specification) e funcionam no Claude Code, Codex, Cursor e outros agentes.

[Read in English](README.md)

## Instalação

```bash
npx skills@latest add eusouosalmo/skills
```

O instalador pergunta quais skills e em quais agentes instalar. Para uma skill só:

```bash
npx skills@latest add eusouosalmo/skills --skill <nome>
```

## Skills

Ainda não há skills publicadas. Elas nascem conforme a necessidade aparece no trabalho real.

As instruções das skills são escritas em inglês; as skills de conteúdo entregam o resultado em pt-BR.

| Categoria | O que reúne |
|---|---|
| [content](skills/content/README.md) | Escrita, roteiro, voz e marca. Resultado em pt-BR |
| [harness](skills/harness/README.md) | Setup de repositório para trabalhar com IA com segurança, inclusive em modo AFK |
