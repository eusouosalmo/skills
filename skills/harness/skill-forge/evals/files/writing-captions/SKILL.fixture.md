# Writing captions

Write the output in pt-BR.

1. Read the script or topic the user gave. If there is none, ask for it.
2. Write a caption with three parts:
   - a first line that repeats the video's hook in other words;
   - two or three short paragraphs with the main idea, each anchored in a concrete number, error or example from the script;
   - a closing question that invites a comment.
3. Keep it under 1,000 characters.
4. Add 3 to 5 hashtags at the end, in lowercase.
