# harness

Skills que preparam um repositório para trabalhar com IA com segurança e qualidade, principalmente em modo AFK, incluindo as skills que o agente usa nele.

- [skill-forge](skill-forge/SKILL.md) (beta): cria ou corrige uma skill a partir de uma falha que você viu acontecer, conferida com evals contra o agente sem a skill.
- [git-guardrails](git-guardrails/SKILL.md) (draft): instala, por projeto, um hook que impede o agente de rodar git destrutivo, com perfis interativo e AFK.
