# harness

Skills que preparam um repositório para trabalhar com IA com segurança e qualidade, principalmente em modo AFK, incluindo as skills que o agente usa nele.

- [skill-forge](skill-forge/SKILL.md) (beta): cria uma skill cedo a partir de trabalho real e a melhora com as correções feitas no uso, com evals que crescem até a promoção.
- [git-guardrails](git-guardrails/SKILL.md) (beta): instala, por projeto, um hook que impede o agente de rodar git destrutivo, com perfis interativo e AFK.
