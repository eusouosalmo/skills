# harness

Skills que preparam um repositório para trabalhar com IA com segurança e qualidade, principalmente em modo AFK, incluindo as skills que o agente usa nele.

- [skill-forge](skill-forge/SKILL.md) (beta): cria ou altera uma skill a partir de uma falha observada, conferida com evals.
- [git-guardrails](git-guardrails/SKILL.md) (draft): guardrails de git por projeto para agentes de código, com perfis interativo e AFK.
