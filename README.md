# skills

Agent skills by [sa/mo](https://eusouosalmo.dev) for writing, scripting videos and setting up repos to work with AI. They follow the [Agent Skills specification](https://agentskills.io/specification) and work in Claude Code, Codex, Cursor and other agents.

[Leia em português](README.pt-BR.md)

## Install

```bash
npx skills@latest add eusouosalmo/skills
```

The installer asks which skills to install and into which agents. For a single skill:

```bash
npx skills@latest add eusouosalmo/skills --skill <name>
```

No skills published yet. They are added as the need shows up in real work.
